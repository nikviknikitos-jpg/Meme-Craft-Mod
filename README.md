# MemeCraftMod (Fabric 1.20.1)

Мемная Мастерская: Моторчик, Аномалия и Колода Совы на Скакалке.

## Управление
- ПКМ Покрышкой по Моторчику — надеть колесо.
- ПКМ пустой рукой по Моторчику — включить/выключить.
- Shift+ПКМ по работающему Моторчику — сорвать колесо.
- ПКМ Колодой — полноэкранная карта-мем с 12 случайными эффектами.
- ПКМ по Кнопке Удачи — 6 мемных событий.
- Бросить палку в Аномалию — 6 человечков.

## Команды
- `/meme_give` — все предметы.

## Сборка
JDK 17, Gradle 8.8, GitHub Actions workflow прилагается.
